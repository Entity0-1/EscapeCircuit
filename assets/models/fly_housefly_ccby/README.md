# Housefly model provenance

The source model was supplied as `housefly.zip`. Its `license.txt` and glTF
metadata identify “Housefly” by schmoldt.art under CC BY 4.0.

- Original model: https://sketchfab.com/3d-models/housefly-5fe7cbd25f9a446d8bae005893d010dd
- Author: https://sketchfab.com/schmoldt.art
- License: https://creativecommons.org/licenses/by/4.0/

The original glTF, binary, textures, and license are preserved here. The game
omits the source scene's display pedestal, scales and reorients the fly, splits
the transparent wing mesh into left and right halves, and animates both on
separate pivots in Godot. The source asset has no built-in animations.

Credit the author, link the model and license, and indicate these changes in
the public game page, repository, and video description.
